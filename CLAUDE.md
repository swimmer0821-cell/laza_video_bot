# CLAUDE.md — «LAZA Видео» (Telegram-бот генерации видео)

ПУБЛИЧНЫЙ репозиторий: всё здесь видит весь интернет. Ни ключей, ни токенов, ни Telegram id людей в файлах быть не должно.

## Что это и кто пользуется
Telegram-бот, который делает ролики для Reels/Shorts из фото товара и анимированного персонажа Лаза (кубик сублимированного мороженого).
Пользуются владелец и те, кому он дал доступ. Бот на русском (озвучка — русский и узбекский).
Работает через платные сервисы: fal.ai (видео и картинки), Higgsfield API (повтор тренда, если задан `HF_KEY`), ElevenLabs через fal (голос), Claude (сценарии), по желанию Azure и Google Gemini (голоса).

## Где работает и как обновляется
- Сервер: тот же, что у бота продаж (DigitalOcean). Папка `/opt/laza_video_bot`, служба `laza_video_bot`.
- Обновление после изменений на GitHub: на сервере команда `laza-video-update` (запускает `update.sh`) или инструмент `bot_update` с `bot=video` коннектора LAZA.
- `update.sh` делает `git reset --hard origin/main`: всё, что на сервере не отправлено в GitHub, будет затёрто. Файл `.env`, база `data/`, логи `logs/` и `.venv` не трогаются.
- Настройки и ключи — только в `/opt/laza_video_bot/.env` на сервере (образец: `.env.example`). Лог: `/opt/laza_video_bot/logs/bot.log`.

## Карта файлов
- `bot.py` — все сценарии бота (видео из фото, персонаж, озвучка, губы, сцены), доступ, защита от двойного нажатия.
- `config.py` — модели и их цены, лимиты, голоса, чтение `.env`.
- `prompts.py` — как Claude пишет промты; здесь же ядро бренда Laza (эмоции, без лекций о технологии и пользы для здоровья).
- `fal_api.py` — запросы к fal.ai. `hf_api.py` — Higgsfield API (оплата за генерацию): «🕺 Повтор тренда» через Genjutsu Light (вариант виден только при `HF_KEY` в `.env`). Второй вариант тренда — Kling 2.6 Motion Control через fal.ai (`fal_api.motion_control`); длина ролика 5/10/15 с на выбор. `voice.py` — озвучка. `media.py` — склейка и обработка видео и звука.
- `db.py` — SQLite: кто имеет доступ и сколько потрачено. `fix_env.py` — чинит `.env` при обновлении.
- `assets/`, `refs/` — эталоны персонажа и реальные фото упаковки.

## Что нельзя ломать
- Доступ: пользоваться ботом могут только `ADMIN_IDS`, `ALLOWED_IDS` и добавленные командой `/add` (`db.is_allowed`). Менять эталоны и добавлять людей — только администраторы.
- Дневной лимит трат `DAILY_LIMIT_USD` на всех: перед КАЖДОЙ платной генерацией проверяется `db.spent_today() + цена <= лимит`. Новую платную функцию без такой проверки не добавлять.
- Перед запуском платной генерации бот показывает цену и ждёт нажатия кнопки; после нажатия кнопка убирается (нельзя нажать дважды). Не запускать платное без подтверждения.
- Одновременно у одного человека идёт один ролик (`BUSY`). Защита от двойного нажатия кнопок (`AntiDoubleClick`) — не убирать.
- Каждая генерация записывается в `gens` со стоимостью и статусом; цены в `config.py` — по данным fal.ai на 21.10.2026, при смене цен обновлять там.
- Персонаж Лаза и упаковка — строго по эталонам из `assets/` и `refs/`; названия вкусов и товаров не выдумывать, логотипов чужих брендов не показывать.
- Правила бренда в `prompts.py` (без лекций о технологии, фабрики, пользы для здоровья, диет) — не менять без владельца.
- `.env` в `.gitignore`; никогда не добавлять в git `.env`, `data/`, `logs/`.

## Как проверять перед публикацией
1. Синтаксис: `python -m py_compile bot.py config.py db.py fal_api.py media.py prompts.py voice.py fix_env.py`.
2. Просмотреть изменения: нет ли ключей, токенов, id людей, адресов в тексте (в публичном репозитории это утечка).
3. Платные запросы к fal.ai для проверки не делать без согласия владельца — каждая генерация стоит денег.
4. После обновления на сервере: `update.sh` печатает «Бот работает»; в логе нет ошибок.

## Как откатить
- `git revert <коммит>`, отправить в `main`, на сервере выполнить `laza-video-update`.
- Если бот не запустился после обновления — посмотреть последние строки лога и откатить коммит.

## Правила работы с владельцем
- Владелец не программист: простыми словами, без терминов, коротко, по шагам.
- Перед изменениями, которые тратят деньги (модели, цены, лимиты, новые платные шаги), — сначала спросить.
- Не коммитить и не пушить без явной просьбы; репозиторий публичный.
- Секреты — только в `.env` на сервере. Образец `.env.example` содержит только пустые поля и безопасные значения.
- Нет данных — писать «уточнить» и спрашивать, не выдумывать.
